## Как сравнивать

Для каждого агрегата вывести:

```text
metric
golden
generated
absolute_delta
relative_delta_pct
classification
explanation
```

Для hardware:

```text
item
golden_qty
generated_qty
delta
source_rule
classification
```

Классификация расхождений:

```text
UNIVERSAL_GEOMETRY
PROVISIONAL_ALPHA_RULE
STUDIO_RULE_REQUIRED
VENDOR_RULE_REQUIRED
INPUT_GAP
BASIS_MANUAL_OR_UNKNOWN
NOT_IMPLEMENTED
```

## Важное правило

Golden benchmark нужен для диагностики, а не для подгонки.

Если generated result отличается от Basis:
1. показать delta;
2. определить вероятную причину;
3. менять правило только при техническом объяснении;
4. каждую временную настройку маркировать `PROVISIONAL_ALPHA`.

Не добавлять скрытые коэффициенты только ради совпадения.

## Что не является критерием точности Construction Core

Не использовать как pass/fail:

- исторические цены;
- коэффициенты заказа;
- округление заказа;
- стоимость работ;
- монтажные тарифы;
- стоимость столешницы.

Главный результат первого этапа — воспроизводимый `JSON → Parts/BOM → benchmark diff`.
